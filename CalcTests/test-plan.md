# Тест-план: модульне тестування CalcClass

Метод: «чорний ящик». Допустима область: int [-2 147 483 648; 2 147 483 647]; параметри типу long, тому значення поза цією областю є недопустимими входами. Код помилки виходу за область — `Error 06` (за прикладом з методички). Ділення на нуль — `Error 09` (специфікація, п. 4.2.4.3 і 4.2.5.3).

## Загальні тест-вимоги

- **T1** — усі вхідні параметри в допустимій області, результат у допустимій області.
- **T2** — перший параметр у області, другий поза областю (або b = 0).
- **T3** — перший параметр поза областю, другий у області.
- **T4** — усі параметри в області, але результат поза областю.

Для унарних методів (ABS, IABS) T2 не застосовується.
